# StockỌja Backend API

This is the Node.js Express REST API server for StockỌja.

## API Endpoints
- `/api/v1/auth/*` - Merchant authentication & tenant context
- `/api/v1/products` - Product catalog management
- `/api/v1/pos/checkout` - POS order processing & stock deduction
- `/api/v1/inventory/*` - Inventory ledger & adjustments
- `/api/v1/orders/*` - Order management
- `/api/v1/storefront/*` - Public storefront REST endpoints

## Getting Started
```bash
npm install
npm run dev
```
